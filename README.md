# IyanTools 2.1.1

Developer: IyanzNotDev

## Instalasi

```bash
git clone https://github.com/IyanzNotDev/IyanTools2.1.1.git
cd IyanTools2.1.1
npm install
node index
```

## Fitur

**OSINT**
- OSINT Number: analisis nomor telepon dari prefix (negara, operator Indonesia).
- OSINT Telegram: info chat Telegram (Chat ID atau @username) lewat Bot API, termasuk jumlah member dan daftar admin.
- OSINT Domain: DNS records, subdomain dari crt.sh, dan info HTTP dasar.
- OSINT Gmail: cari profil publik Gravatar dari alamat Gmail.
- BreachGmail: cek email di data kebocoran.
- Stalker: cek profil publik dari username di GitHub, TikTok, Roblox, YouTube, dan Minecraft.
- Username Checker: cek ketersediaan username di beberapa platform.
- IP Lookup: info dari alamat IP.

**Cek Data**
- Check NIK
- Check Kode Pos

**Web dan Scan**
- Scrape Website
- API Checker: cek status API yang dipakai aplikasi.
- Nmap Port Scanner
- SQLmap SQL Injection Check
- ParamSpider Parameter Discovery
- Obfuscator Analyzer / Decoder

**Lain-lain**
- Message Telegram: cek Bot Token, lihat info bot, dan kirim pesan ke Chat ID.
- Temp Email: email sementara dan baca pesan masuk.
- Anichi
- Psychology Search
- AI Assisten
- TikTok LIVE Chat
- Hafe Fun: teka-teki (soal MTK acak dan tebak-tebakan).
- Custom Color Menu
- History
- Help

## Catatan

- Nmap dan SQLmap hanya boleh dipakai untuk target yang kamu punya izinnya.
- Semua fitur OSINT hanya memakai da
ta publik.
